# Xerro Hub System

Customizable UI Hub with Fly and Noclip Features

## Features

- Customizable UI with text and color
- Fly and Noclip features

## Requirements

- FiveM server
- ESX Framework

## Installation

1. Download the script
2. Place the script in your FiveM server's resources folder
3. Add `start xerro-hub-system` to your server.cfg

## Usage

- Use the `/hub` command to open the UI
- Press `E` to toggle fly mode
- Press `Left Shift` to toggle noclip mode
- Press `Backspace` to close the UI

## Configuration

Edit the `config.lua` file to customize the UI color, text, position, size, and speeds.
